frus has a site of its own. The README's list of known gaps had one line that was not about
code: *a searchable documentation site*. This is it.

<!-- truncate -->

The pages are not a second copy of the documentation. They are the repository's own —
`docs/getting-started.md`, the guide under `docs/guide/`, the architecture notes and the
`frus` command's reference — copied in when the site is built. Each example in them is still
a complete piece of Rust that frus's test suite compiles, so what you read here is what
compiles today.

What you will find:

- **[Get started](/docs/getting-started)**: install the `frus` command, make a project, and
  run it on this computer, a phone and the browser.
- **[The guide](/docs/guide)**: one topic per page, from laying out a screen to the tray and
  the taskbar.
- **[The widget catalog](/widgets)**: the twelve families of widgets, and the live gallery, which
  is frus itself built for the web.
- **The blog**: what each release brings, starting with the last two.

frus is pre-alpha. If something on these pages is wrong, unclear or missing, every page has
a link to edit it on GitHub, and [issues](https://github.com/KalybosPro/frus/issues) are
open — in English or in French.
