# The frus name and logo

The code of frus is open source under MIT OR Apache-2.0. Those licenses cover the code; they do not grant rights to the project's name or logo. This page says how they may be used. "frus" and the frus logo identify the project started and maintained by KalybosPro.

The aim is simple: anyone who sees the name should know whether they are getting the original project.

## Use freely

- Say that your application is built with frus, or that your package works with frus.
- Write about frus, teach it, or compare it with other tools.
- Keep the logo as the default icon of an application made with frus.
- Name a companion crate in a way that makes the relationship clear, such as `acme-for-frus`.

## Ask first

- Selling a product or service whose name includes "frus".
- Using the logo in your own product's branding, or in a way that suggests endorsement.

## Please do not

- Publish a modified version or a fork under the name "frus", or a name easily confused with it. A fork is welcome under a name of its own, with the copyright notices and `NOTICE` file kept as the licenses require.
- Name a crate, package or domain so that it looks official, such as `frus-core-plus` or `frus-official`.
- Suggest that the project endorses you or your work when it does not.

To ask for permission or report a misuse, open an issue at <https://github.com/KalybosPro/frus/issues> or write to kalyboskokou1@gmail.com.
