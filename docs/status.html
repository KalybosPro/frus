Where we have just arrived

The arc of the session: J267 → J276

Two ergonomic leaps, then the whole async stack, then the ground cleared for a fourth platform.

J267 – J268
One entry point + the facade
frus::main!(App::default()) — one declaration, one dependency, three platforms wired.
J269
compute_scroll fills the constrained axis
A Scroll now fills the space it is given — no more "filler" container on the application side.
J270 – J272
The asynchronous stack
perform_async, a cross-platform fetch, then a Request builder (POST, headers, timeout) behind the net feature.
J273 – J275
From the effect to the domain type
An end-to-end example, the RemoteData idiom for the four states, and typed JSON in and out behind the json feature.
J276
Named platform cfgs
"Desktop" no longer means "not the others" — so adding iOS stops silently inheriting the desktop clipboard, logger and a11y backend.
